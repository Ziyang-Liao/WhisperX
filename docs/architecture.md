## 1b. System overview (logical)

```mermaid
flowchart TB
    user([User / Browser])

    subgraph edge[Edge]
        cf[CloudFront<br/>only public entry]
    end

    subgraph ec2[EC2 - CPU instance]
        api[FastAPI<br/>API + static SPA]
        worker[Background worker<br/>WhisperX model loaded once]
        api -.enqueue via DB.-> worker
    end

    subgraph aws[AWS services]
        s3[(Amazon S3<br/>videos + SRT/VTT)]
        bedrock[Amazon Bedrock<br/>Claude Haiku]
        db[(SQLite<br/>media + tracks)]
    end

    user -->|HTTPS| cf
    cf -->|HTTP + X-Origin-Secret| api
    api --> db
    worker --> db
    api -->|presigned URL| s3
    user -.->|presigned PUT/GET direct| s3
    worker -->|get video / put subtitles| s3
    worker -->|translate segments| bedrock
```

The security group only admits CloudFront's managed prefix list, and the app
rejects any request lacking the `X-Origin-Secret` header CloudFront injects — so
the instance cannot be reached except through CloudFront.

## 2. Upload to subtitle - end-to-end sequence

![End-to-end sequence](diagrams/sequence_end_to_end.png)

<details>
<summary>Mermaid source for the sequence diagram</summary>

```mermaid
sequenceDiagram
    actor U as Browser
    participant CF as CloudFront
    participant API as FastAPI
    participant S3 as S3
    participant W as Worker
    participant WX as WhisperX
    participant BR as Bedrock Claude

    Note over U,API: 1. Upload (bytes go straight to S3)
    U->>CF: POST /api/media {filename}
    CF->>API: + X-Origin-Secret
    API->>U: media_id + presigned PUT URL
    U->>S3: PUT video bytes (direct)
    U->>CF: POST /api/media/{id}/complete
    CF->>API: + X-Origin-Secret
    API->>API: mark status = pending

    Note over W,WX: 2. Transcription (async, on the worker)
    W->>S3: download video
    W->>WX: extract audio + transcribe + align
    WX-->>W: segments + detected language
    W->>S3: put source SRT/VTT
    W->>API: status = completed, source track ready

    Note over U,BR: 3. Translation (user picks target languages)
    U->>CF: POST /api/media/{id}/subtitles {targets}
    CF->>API: + X-Origin-Secret
    API->>API: create pending track per language
    W->>BR: translate segments (per language)
    BR-->>W: translated text (1:1 with source)
    W->>S3: put translated SRT/VTT

    Note over U,S3: 4. Download / preview
    U->>CF: GET /api/media/{id}/subtitles/{lang}/{fmt}
    CF->>API: + X-Origin-Secret
    API->>U: presigned GET URL
    U->>S3: GET subtitle file (direct)
```

</details>

## 3. Processing pipeline

```mermaid
flowchart LR
    A[Video in S3] --> B[ffmpeg<br/>extract 16kHz mono wav]
    B --> C[WhisperX transcribe<br/>auto-detect language]
    C --> D[wav2vec2<br/>word alignment]
    D --> E[Source segments<br/>with timestamps]
    E --> F[Source SRT/VTT]
    E --> G{Target languages}
    G -->|per language| H[Claude on Bedrock<br/>per-segment translate]
    H --> I[Reuse source timestamps]
    I --> J[Translated SRT/VTT]

    style F fill:#d1fae5
    style J fill:#d1fae5
```

Translation reuses each source segment's start/end and only replaces the text,
so subtitle timing stays aligned across every language.

## 4. Data model

```mermaid
erDiagram
    MEDIA_FILE ||--o{ SUBTITLE_TRACK : has

    MEDIA_FILE {
        int id PK
        string filename
        string media_type
        string s3_key
        float duration
        string format
        string source_language
        string transcription_status
        text transcript_json
    }
    SUBTITLE_TRACK {
        int id PK
        int media_file_id FK
        string language
        bool is_source
        string status
        string srt_s3_key
        string vtt_s3_key
    }
```

One media file owns N subtitle tracks: one source-language track produced by
transcription, plus one track per requested target language. The pair
`(media_file_id, language)` is unique.

## 5. Status state machines

A media file's transcription status:

```mermaid
stateDiagram-v2
    [*] --> created: POST /media
    created --> pending: upload complete
    pending --> processing: worker picks up
    processing --> completed: transcript + source track
    processing --> failed: error
    failed --> pending: retry
```

A subtitle track's status (the translation queue):

```mermaid
stateDiagram-v2
    [*] --> pending: language requested
    pending --> processing: worker picks up
    processing --> completed: SRT/VTT in S3
    processing --> failed: error
    failed --> pending: regenerate
```

```mermaid
    viewer -->|HTTPS| cf
    cf --> sg
    sg --> inst
    inst -. assumes .-> role
    inst --> bkt
    inst --> br
```

</details>

> No custom domain in this environment, so CloudFront-to-origin is HTTP while
> viewer-to-CloudFront is HTTPS. End-to-end TLS needs a domain + ACM (+ ALB) —
> see the design doc's Phase 4.
